# draw.io 互換性とテスト範囲

調査日: 2026-10-04

## 比較対象

- 公式エディタ: [`jgraph/drawio` の `dev` ブランチ](https://github.com/jgraph/drawio/tree/2201e54124bfbbf09d8addec60e6f8d73eed6f92)。この時点の公開ツリー 3,380 項目を調べた限り、`test/`、`tests/`、`*.test.js`、`*.spec.js` などのテスト一式は見つからなかった。[公開 CI](https://github.com/jgraph/drawio/tree/2201e54124bfbbf09d8addec60e6f8d73eed6f92/.github/workflows) はリリース用 WAR ビルドと stale issue 管理で、互換性テストを提供していない。非公開のテストについては判断できない。
- 形式の基準: 公式の [XML 書き出し説明](https://www.drawio.com/docs/manual/export/export-to-xml/)、[読み込み形式一覧](https://www.drawio.com/docs/manual/import/import-formats/)、公式組織が公開する [`mxfile` スキーマ](https://github.com/jgraph/drawio-mcp/blob/main/shared/mxfile.xsd) と [スタイル資料](https://github.com/jgraph/drawio-mcp/blob/main/shared/style-reference.md)。
- Dorojam: [`src/main.js`](../src/main.js) の import/export 実装と [`test/pages.test.js`](../test/pages.test.js) のテスト。

公式テストに対するカバレッジ率は、比較できる公開テスト一式がないため算出できない。以下は**実装範囲**と**このリポジトリで自動検証済みの範囲**を別々に示す。

| 領域 | Dorojam の実装 | 自動テスト | 主な差分 |
| --- | --- | --- | --- |
| 非圧縮 `.drawio` / XML | 読み込み・書き出し | 2 ページ・各 1 個の四角形を持つ合成 XML で往復 | 公式アプリが生成した実ファイルでは未検証 |
| 複数ページ | ページ名と要素を読み込み、全ページを書き出す | 2 ページの切り替え、名前とセル ID の保持 | ページ固有の表示設定などは保持しない |
| 圧縮された `<diagram>` | `DecompressionStream` を使う読み込み経路がある | なし | 圧縮形式の実ファイル、ブラウザ差異は未検証。書き出しは非圧縮のみ |
| 図形 | 四角形、楕円、ひし形、付箋、セクション、テキストを対応付ける | 四角形のみ | その他の公式図形は四角形として読み込まれ、元の種類を保持しない |
| 線・コネクタ | 始点・終点の参照と直線を読み書き | なし | 経由点、線種、矢印種類、ラベルなどを保持しない |
| スタイルと文字 | 塗り色、線色、文字サイズ、プレーンテキストの一部を読む | なし | HTML 装飾、フォントや配置、その他の多数のスタイル指定を保持しない |
| グループ・レイヤー | `vertex` セルを列挙する | なし | 親子関係と相対座標を再現・保存しない |

| その他の読み込み形式 | `.drawio` と `.xml` のみ | 非圧縮 `.drawio` の合成 XML のみ | 公式が対応する VSDX、Gliffy、画像などは未対応 |

| 公式 draw.io との相互運用 | XML 構造に合わせて出力する | なし | 公式エディタで開く・編集・再保存する実機往復は未実施 |

## 現在のテストの正確な範囲

`npm test` で実行されるテストは 1 件。旧形式のローカル保存データ移行、ページ操作、**手書きした最小の非圧縮 XML** の読み込み、ページ切り替え、全ページの XML 書き出し、保存を検証する。圧縮ファイル、コネクタ、複雑な図形、公式アプリが生成したファイルはテストデータに含まれない。

したがって現状は「基本的な XML の一部を扱える」段階であり、draw.io ファイル全般との互換性は保証できない。互換性を計測するには、公式アプリで作成した代表的な `.drawio` ファイルを固定のサンプルとして追加し、読み込み後の表示と再保存で保持すべき情報を個別に検証する必要がある。
